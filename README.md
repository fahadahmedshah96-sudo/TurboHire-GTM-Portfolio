# TurboHire GTM Context Library

**Purpose:** Shared, source-aware context for TurboHire PMM research and content workflows.

**Reviewed:** 12 November 2026  
**Use:** Load the relevant files before drafting or analyzing. For any product, legal, customer, or performance claim, check `source-priority-and-claim-status.md` first.

## Files

- [`positioning.md`](positioning.md) — category, audience problem, solution narrative, and message hierarchy.
- [`product-and-claims.md`](product-and-claims.md) — product architecture, capability boundaries, and claim rules.
- [`icp-and-use-cases.md`](icp-and-use-cases.md) — audience, buying context, industries, and hiring scenarios.
- [`voice-and-format-rules.md`](voice-and-format-rules.md) — shared voice and format-specific rules for decks, blogs, reports, and social content.
- [`source-priority-and-claim-status.md`](source-priority-and-claim-status.md) — source hierarchy, public-safety guidance, and claim-status labels.

## Instructions for an agent

1. Treat these files as working context, not as permission to publish internal or confidential material.
2. Use the latest approved source for the exact audience, region, product maturity, and deliverable.
3. If sources disagree, flag the conflict and prefer the higher-priority source. Do not silently combine claims from different regions or product releases.
4. Never invent customer outcomes, statistics, integrations, product availability, ROI, or quotations.
5. Keep human judgment and accountability visible whenever AI-assisted evaluation or hiring decisions are discussed.
6. Before external publication, verify that each company-specific detail is publicly available and current.

## Scope note

This library is a personal PMM portfolio research aid. It is not an official TurboHire product specification or approved corporate publication. Product availability and claims can change; confirm them with current authorized company materials before using them externally.
